在阅读java源码的时候，我们经常能够看到这样的一大堆注释：

[

![](https://www.freebytes.net/wp-content/uploads/2022/03/image.png)

]()

这种大量注释，对于英文一般的人来说，只能求助百度翻译了。但是如果你直接复制上去，会发现翻译得不如人意。那是因为这段注释有很多*、@、<i>等等这种符号，这会影响翻译器的分析。

所以分享一个能够格式化java源码注释的在线工具，只要把注释复制上去，点击“替换”按钮，就可以格式化注释文本了。
